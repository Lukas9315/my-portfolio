# Portfolio

Prosta, statyczna strona-portfolio: o mnie, doświadczenie, stack i kilka notatek o Reakcie.

Zbudowana na Next.js (App Router) + Tailwind CSS. Cała treść siedzi w `content/`:

- `content/profile.ts` — dane, doświadczenie, stack, hobby, kontakt
- `content/posts.ts` — wpisy na blogu

## Development

```bash
pnpm install
pnpm dev
```

Strona pod http://localhost:3000.

## Build

```bash
pnpm build
```
